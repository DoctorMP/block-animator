Add scroll-triggered CSS animations to any block in the WordPress block editor.

== Description ==

Block Animator lets you animate any block as it scrolls into view — no shortcodes, no page builder lock-in, just an extra panel in the block editor's settings sidebar.

This plugin is in early development. Details will be filled in as features land.
